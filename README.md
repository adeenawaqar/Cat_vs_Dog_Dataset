 # Project Overview

A Deep Learning-based image classification system designed to distinguish between Cats and Dogs using a Convolutional Neural Network (CNN). The project focuses on achieving high accuracy while solving common machine learning challenges like overfitting.

# **Key Features:**

**Large Scale Dataset:** Trained on 25,000 images from the Microsoft PetImages dataset.

**Deep Architecture:** Utilized a 4-layer Convolutional Neural Network (CNN) for detailed feature extraction.

**Overfitting Prevention:** Successfully reduced the gap between training and validation accuracy using Data Augmentation and Dropout Layers.

**Clean Data Pipeline:** Implemented an automated filter to skip corrupt JPEG images during the training process.

**High Performance:** Achieved a solid 89.76% Validation Accuracy.


# **Technologies Used**


Python (Core Programming)

TensorFlow / Keras (Deep Learning Framework)

Matplotlib (Data Visualization & Loss/Accuracy Graphs)

Numpy (Array Manipulation)


# **Learning Outcomes**


**Data Augmentation:** Learned how to synthetically increase dataset variety using rotations, flips, and zooms.

**Model Optimization:** Fine-tuned hyperparameters and layer depth to balance model complexity and performance.
